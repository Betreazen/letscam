# Разработка LetsCam

Как устроен мод, как его собрать и проверить. Полная спецификация и журнал проверок — [design/01-spec.md](design/01-spec.md).

## Устройство

Логика живёт в крейте, игра его только зовёт:
- правка крейта пересобирается за ~11 с;
- правка хелпера бандла — за ~48 с.

**`mod/letscam/` — бандл Horizon.** Манифест `horizon-mixin.toml`: 8 модулей и 11 инъекций HEAD. В нём тонкие хелперы и модули игры:

| Файл | Что делает |
|---|---|
| `glue.rs` | запись, рендер, клавиши, команды, HUD |
| `screen.rs` | окно записей (F10) |
| `edit.rs` | редактор ключевых кадров |
| `world.rs` | время суток и реестры для реплея |
| `shot.rs` | фокус и поза камеры рендера |
| `labels.rs` | фазы атак SoulsCraft для листов кадров |
| `diag.rs` | диагностика синхронизации модели игрока в логе |
| `bridge.rs` | публичный модуль рендер-крейта, передаёт кадры из видеокарты |

**`mod/letscam/engine/` — крейт `letscam-engine`, от игры не зависит.** В нём:

| Модуль | Что делает |
|---|---|
| `config.rs` | настройки с русскими комментариями |
| `loopback.rs` | звук игры: WASAPI process loopback |
| `mic.rs` | микрофон через cpal |
| `session.rs`, `recording.rs` | сессия записи: дорожки, события интерфейса, след игрока |
| `director/` | камера-режиссёр: плечо, двери, потолок, облёт при открытом инвентаре |
| `encoder.rs`, `encode.rs` | ffmpeg: NVENC или программный кодек, две аудиодорожки |
| `pip.rs` | интерфейс картинкой в картинке |
| `sheet.rs`, `mob_labels.rs` | листы кадров и подписи фаз атак |
| `render.rs`, `render_stats.rs` | задание рендера и его тайминги |

Серверной части нет. На общем стенде мод собирается только в клиент: `"side": "client"` в `mods.json` стенда.

## Тесты крейта

```bash
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings
cargo nextest run --workspace
```

Среди тестов:
- реальные записи дома и капсулы RustCraft, прогоняемые кадр за кадром (`director/tests_scenes.rs`);
- сборка роликов и листов кадров настоящим ffmpeg.

Тестам с ffmpeg нужен `ffmpeg` в `PATH` или `C:\ffmpeg\bin`.

## Общий стенд

Моды сервера автора собираются и проверяются вместе на общем стенде `horizon-joint-dev`, со своим `joint.ps1`.

```powershell
.\joint.ps1 stage -Mod letscam
.\joint.ps1 client
```

Сценарии гоняет офлайн-бот `lc_a` в своей части мира: x от −1000 до 0, z от −1000 до 0. Перед прогоном сервер стенда запускается в офлайн-режиме, после прогона его закрывают:

```powershell
.\joint.ps1 open; .\joint.ps1 serve -Owner letscam
& tools\bench-test.ps1      # дом с дверью, ревенант SoulsCraft, редактор ключей, 4–5 ракурсов, ffprobe
& tools\capsule-scene.ps1   # капсула RustCraft, focus=ride
.\joint.ps1 stop -Owner letscam; .\joint.ps1 close
```

Сценарии:
- никогда не пишут настоящий микрофон (`record_mic = false`);
- запускают бота без звука;
- кладут ролики в `F:\letscam\joint-dev`.

После рендера в логе клиента остаются три строки:
- `letscam: render stats` — тайминги кодировщика;
- `letscam: render loop` — кадры игры на кадр ролика, повторы захвата, время позы камеры;
- `letscam: mob labels` — подписи фаз атак.
